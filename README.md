# Student Management System (Python + CSV)

A simple and beginner-friendly Student Management System built using Python and CSV file storage.

The application provides a menu-driven command-line interface to manage student records using CRUD operations.

## Features

- Register New Student
- Display All Students
- Find Student by Roll Number
- Modify Student Details
- Remove Student
- Count Total Students
- Persistent CSV data storage
- Menu-driven command-line interface

## Technologies Used

- Python 3
- CSV Module
- File Handling
- Command Line Interface (CLI)

## How to Run

### 1. Install Python

Make sure Python 3 is installed on your system.

### 2. Clone the Repository

git clone https://github.com/gs0774467-hue/student-management-system-python.git

### 3. Open the Project Folder

cd student-management-system-python

### 4. Run the Program

python Student_management_system.py
